# Sharing plan

The former custom package service plan is superseded by the [GitHub sharing adoption plan](GITHUB-SHARING-PLAN.md).

Students share from their existing game repository. Related reusable classes live in `libraries/<slug>/`; whole games are separate editable project releases. GitHub issues record frozen publication requests, the Git registry reserves immutable versions, and public Blob storage serves ordinary Maven and ZIP files. Vercel remains the website host; the replacement has no Neon dependency.

## Curation and capacity follow-up

[The owner-approved policy](ZEROHUB-POLICY.md) still applies: no lifetime contributor allowance, and maintainers retain catalog curation authority. Withdrawal records status without assigning an accepted version to new bytes. Deletion, retention budgets, alerts and live rollout require concrete operator evidence. Generic library execution remains closed until its outstanding acceptance gate is resolved; local Check does not resolve it.
