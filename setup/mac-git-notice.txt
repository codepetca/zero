Zero includes Git 2.56.1 from GitHub Desktop's Dugite Native project.
Zero packages a subset of the upstream binaries and scripts and replaces one
duplicate executable with a relative symbolic link.

Git is licensed under the GNU General Public License version 2. See COPYING.
The complete corresponding source is provided alongside the Zero Mac download
as git-2.56.1-source.tar.gz and dugite-native-2.56.1-build-source.tar.gz.
The latter contains the upstream build scripts. Zero's packaging script is
setup/package-mac-git.py in the Zero source for this release.
