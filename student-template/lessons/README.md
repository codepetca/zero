## Start a lesson

Before starting a project, complete [account/privacy setup](https://zero.codepet.ca/docs/setup#before-lesson-0-github-and-privacy)
and [Zero setup](../README.md#first-setup): your own verified GitHub account,
Git 2.31+, school access and permission to share public source. Repositories
created through Zero are public, including source and included files; keep
secrets and private material out. Follow your school policy if it requires a different arrangement.

For each of Greeting, Coin and Pet (or the optional Study project), sign in to
GitHub and complete access setup. On the Zero Start Page, choose:

**Project → New**

Enter a name and clone location, then choose **Clone here**. Zero creates your own repository
and opens its clone. Each first lesson tells you how to prepare its starting code.
To reopen your own clone, choose:

**Project → Open**

Keep the same repository throughout each project's lessons.

You write the controls, game objects and logic in each project. Save, choose **Run**, then **Commit & push** at the
checkpoints in the lessons. At the end, use **Publish & open app** and test your
work in a browser when you have permission to share it publicly. A published
page and its included assets are public. If a school account or repository cannot
publish, follow your school or account policy; do not change visibility without
approval. Once cloned, local Run works offline after dependencies are cached.

Pet uses the [Pet assets ZIP](https://zero.codepet.ca/generated/learning-assets/pet-assets.zip).
The optional Coin media lesson has its own [game assets ZIP](https://zero.codepet.ca/generated/learning-assets/game-assets.zip).
Use assets you created or have permission to share. Coursework repository links
go separately to [Pika](../README.md#your-repository-and-pika).
