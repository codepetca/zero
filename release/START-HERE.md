# Start with Zero

1. Install a supported **JDK 17+** and **VS Code**. Your first build needs internet
   for Maven and JavaFX downloads. Students do not need Node.js or global Maven.
2. In VS Code, open the **starter** folder beside this file. Keep the whole folder
   together, including its hidden .mvn and .vscode folders.
3. Open Extensions, choose **Install from VSIX…**, and select **zero-0.5.0.vsix**
   beside this file. Install the Java extensions recommended by the starter.
4. Open src/main/java/Main.java. Use **Zero: Run App** or the standard build
   shortcut to open the quiz. Change a question, save, and run again.
5. Read starter/README.md for running, examples, exercises and GitHub steps;
   starter/API.md describes the readable framework shipped inside your project.

If you prefer a light teaching profile, import optional/Zero.code-profile **before**
installing extensions in that profile. The optional keybindings file contains
F6/F7 shortcuts you can add yourself.

From a terminal inside starter, run **./mvnw clean compile javafx:run**.
On Windows use **.\mvnw.cmd clean compile javafx:run**.

Running locally needs no GitHub account. Upload, Start and Finish default to
simulation. Follow teacher visibility instructions before creating your own
repository or enabling live uploads. Submit the repository link separately in Pika.

The Component Workshop is a separate optional download. The starter already
includes readable examples and editable ordinary Java framework source.
