# Zero Portable for Windows

1. In File Explorer, right-click the ZIP and choose **Extract All**. Use a
   short folder path on the local computer where the school allows apps to run.
2. Open **Zero Portable** and double-click **Zero.exe**. Keep the files and the
   **tools** folder together. The package includes VSCodium, Java, Git, Node.js,
   and Java language support.
3. Choose **Sign in to Zero** if prompted. Open the Command Palette with
   **Ctrl+Shift+P**, choose **Zero: Troubleshooting**, then **Test installation**.
   Click **Run test** and check that the sample window opens. Sign-in and the
   first build need internet access.

Use Windows 10 x64 (build 19041 or later) or Windows 11 x64 with .NET Framework
4.8. School policy must allow Zero and its tools to run. Keep projects in your
approved workspace. Zero keeps each Windows user's profile separately.
