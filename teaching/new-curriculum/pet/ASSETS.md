# Asset provenance

`resources/pet/bird-flap-sheet.png` is an unmodified copy of `student-template/examples/sprite-playground/src/main/resources/bird-flap-sheet.png`. That example identifies it as original Image Gen artwork created for Sky Hop, reused under the repository MIT license. It has four wing poses in a 2×2 atlas. The lower row is offset by 30 source pixels, so this lesson uses the example's explicit region coordinates.

`resources/pet/chime.wav` is an unmodified copy of `student-template/examples/media-demo/resources/media-demo/chime.wav`. The media-demo README identifies it as an original Zero asset covered by the repository MIT license: a 0.12-second mono 44.1 kHz, 16-bit PCM chime. No third-party asset is included.
